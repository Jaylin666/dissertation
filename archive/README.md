# Archive

This directory retains scientific provenance needed to understand and verify
the dissertation analyses. It is not the recommended reproduction entry
point.

- `legacy_steps/` contains scientifically relevant chronological analysis and
  validation scripts that were not promoted into the modular implementation.
- `research_outputs/` contains selected compact source and validation
  artefacts required by current checks or controlled-evidence provenance.

Writing/export helpers, experiment-planning material, superseded meeting
outputs, and completed refactor working records are not part of the final
technical deliverable. Their earlier versions remain available in Git history.

Use `code/`, `tests/`, and `outputs/dissertation_evidence/` for the supported
implementation, automated checks, and dissertation evidence respectively.
