# Archive

This directory retains research history for auditability. It is not the
recommended reproduction entry point.

- `legacy_steps/` contains the original chronological scripts that were not
  promoted into the modular implementation.
- `research_outputs/` contains compact historical meeting outputs that
  preceded the controlled Chapter 4 and Chapter 5 evidence packages.
- `refactor_history/` contains the completed modular-refactor plan,
  inventories, and regression records.

Use `code/`, `tests/`, and `outputs/dissertation_evidence/` for the supported
implementation, automated checks, and dissertation evidence respectively.
